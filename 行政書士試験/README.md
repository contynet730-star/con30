## 試験のしくみ

令和6年度から「一般知識等」が「行政書士の業務に関し必要な基礎知識」に変わり、行政書士法等の関連諸法令が明示的に出題範囲へ入りました。令和9年度もこの枠組みが続く前提で作っています。

出題形式と配点は次のとおりです。

| 形式 | 問数 | 配点 |
| --- | --- | --- |
| 法令等・5肢択一式 | 40 | 160点 |
| 法令等・多肢選択式 | 3 | 24点 |
| 法令等・記述式 | 3 | 60点 |
| 基礎知識・5肢択一式 | 14 | 56点 |
| 合計 | 60 | 300点 |

合格には次の3つをすべて満たす必要があります。

- 法令等科目で122点以上（244点の5割）
- 基礎知識科目で24点以上（56点の約4割、択一6問以上）
- 全体で180点以上（300点の6割）

基礎知識の足切りは択一6問正解が目安です。ここを落とすと法令等が満点でも不合格になるため、行政書士法と個人情報保護法は確実に取れるようにしておきます。

試験は例年11月の第2日曜日、午後1時から午後4時までの3時間。出題の根拠となる法令は、試験を実施する年度の4月1日現在で施行されているものです。令和9年度なら令和9年4月1日時点が基準になります。日程と受験要項は一般財団法人行政書士試験研究センターの公式発表で必ず確認してください。

## 1年間の進め方

本試験まで約14か月あるので、75日の周回を重ねる形で組み立てます。

**第1周（約2.5か月）** 全問を初見で解きます。正答率は気にせず、解説を読んで論点の存在を知ることが目的です。間違えた問題のIDを手元にメモします。

**第2周（約2.5か月）** 同じ75日をもう一度回します。ここで正答率7割を目指します。2周連続で間違えた問題が自分の弱点です。

**第3周以降** 間違えた問題だけを回すと1日の所要時間が縮むので、空いた時間を条文素読と過去問演習に回します。行政手続法、行政不服審査法、行政事件訴訟法は条文そのものが出題されるため、条文を通しで読む時間を別に確保してください。

**直前2か月（9月・10月）** 市販の模試か予想問題集で3時間通しの演習を月2回入れます。この問題集は知識の維持用として、間違えた問題だけを毎日回します。

## 学習の優先順位

配点上、行政法が112点前後、民法が76点前後で、この2科目だけで全体の6割を超えます。時間が取れない日は行政法と民法を優先してください。

憲法は判例知識が中心で、条文だけでは解けません。この問題集の憲法45問はすべて判例か条文に紐づけてあるので、解説の事件名は覚えるようにします。

商法・会社法は5問20点に対して範囲が広く、費用対効果が低い分野です。会社法の機関設計と株式、商法総則の商行為あたりに絞るのが現実的です。

記述式60点は合否を分けます。40字という字数感覚は書いてみないと身につかないので、週末チェックの記述問題は頭の中で済ませず実際に書いてください。

## 注意点

法改正が反映されている論点を含みます。特に次のものは令和9年度試験で出題される可能性が高いので、条文を最新のもので確認してください。

- 民法の離婚後共同親権（令和6年改正、令和8年4月1日施行）
- 嫡出推定制度の見直しと再婚禁止期間の廃止（令和4年改正、令和6年4月1日施行）
- 相続登記の申請義務化（令和6年4月1日施行）
- 懲役・禁錮から拘禁刑への一本化（令和7年6月1日施行）
- 所有者不明土地関連の民法改正（令和5年4月1日施行）

この問題集は学習用の教材であり、公式の過去問ではありません。条文番号や判例は作成時点のものです。最終的な確認は六法と公式資料で行ってください。

## ファイル構成

```
行政書士試験/
├── README.md              この文書
├── daily/                 日割りの問題（INDEX.md が目次）
├── data/                  問題データ（分野別JSON）
├── scripts/build.py       daily/ を生成するスクリプト
└── questions_all.json     全問題を統合したデータ（Webアプリ用）
```

問題を追加・修正するときは `data/` のJSONを編集してから次を実行します。

```
python3 scripts/build.py
```
