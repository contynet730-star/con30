# SNS運用チーム

テーマ: **小学校教育あるある**

Claude Codeのサブエージェントとして構成された6名のSNS運用チームです。
このセッションで「〜担当に◯◯させて」と依頼すると、該当エージェントが動きます。

## チームメンバー

| 役割 | エージェント名 | 担当領域 |
|------|---------------|----------|
| 戦略責任者 | `sns-strategist` | 発信方針・方向性の設計、KPI設定 |
| リサーチ担当 | `sns-researcher` | 競合分析・市場調査・トレンド調査 |
| 企画担当 | `sns-planner` | 投稿企画・ネタ出し・投稿カレンダー |
| 編集担当 | `sns-editor` | 投稿作成・推敲・改善提案 |
| マーケ担当 | `sns-marketer` | note導線・有料コンテンツの販売設計 |
| 秘書担当 | `sns-secretary` | タスク管理・進行管理・議事録 |

## 使い方の例

- 「戦略責任者に発信方針を作らせて」
- 「リサーチ担当に教育系アカウントの競合分析をさせて」
- 「企画担当に今月の投稿ネタを10本出させて」
- 「編集担当にこのネタでX投稿を3案書かせて」
- 「マーケ担当にnoteの有料記事の設計をさせて」
- 「秘書担当に今の進捗をまとめさせて」

## ディレクトリ構成

```
SNS運用チーム/
├── README.md            ← このファイル
├── 00_タスクボード.md    ← 秘書担当が管理
├── 01_発信方針.md        ← 戦略責任者が管理
├── 02_リサーチ/          ← リサーチ担当の調査レポート
├── 03_企画/              ← 企画担当のネタ・企画書
├── 04_投稿/              ← 編集担当の投稿文
├── 05_マーケ/            ← マーケ担当の導線・販売設計
└── 06_議事録/            ← 秘書担当の記録
```

## 標準ワークフロー

1. **戦略** が方針を決める
2. **リサーチ** が競合・市場を調べる
3. **企画** がネタ・企画を出す
4. **編集** が投稿文に仕上げる
5. **マーケ** がnote導線につなげる
6. **秘書** が全体の進行をタスクボードで管理する

## 共通ルール

- 特定の学校・個人・自治体が特定される内容、児童の個人情報に触れる内容は扱わない
- 批判・炎上狙いではなく「共感と実用性」で伸ばす
- 成果物はすべてこのディレクトリ配下にMarkdownで残す
