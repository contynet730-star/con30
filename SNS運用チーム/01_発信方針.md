# 発信方針（初版）

作成: 戦略責任者（`sns-strategist`）
作成日: 2026-07-05
ステータス: 初版（リサーチ結果を反映して確定版に更新予定）

## 1. アカウントコンセプト

**「現場を知っているから笑える、現場を知っているから役に立つ。小学校教育あるある」**

小学校教育の現場経験に裏打ちされた「あるある」で共感を集め、その先にある実用的なノウハウ（note）へつなげる。

## 2. 想定読者（優先順）

1. **現役の小学校教員**（メイン）— 「わかる〜！」の共感と、明日使える工夫を求めている
2. **教員志望の学生・若手教員** — 現場のリアルを知りたい、失敗を先回りで避けたい
3. **小学生の保護者** — 学校の裏側への興味、先生との付き合い方のヒント

## 3. 提供価値

| 価値 | 内容 | 主な形式 |
|------|------|----------|
| 共感 | 現場の解像度が高い「あるある」で笑える・救われる | SNS投稿（無料） |
| 発見 | 保護者・学生が知らない学校の裏側がわかる | SNS投稿・無料note |
| 実用 | 学級経営・保護者対応・校務効率化の具体ノウハウ | note（無料→有料） |

## 4. トーン&マナー

- **あたたかい笑い**: 自虐やユーモアはOK。ただし誰かを見下す笑い・愚痴で終わる投稿はNG
- **現場の語彙**: 「所見」「校務分掌」「個人面談」など現場の言葉を自然に使いリアリティを出す
- **前向きな後味**: クスッと笑って、ちょっと元気になれる読後感で締める

## 5. 絶対NGライン

- 特定の学校・個人・自治体・実在の事案が特定される内容
- 児童の個人情報、児童を揶揄する内容
- 炎上狙いの批判・断定的な教育論争への参戦
- 誇大・不安煽りの訴求

## 6. コンテンツファネル

```
SNS投稿（あるある共感）
  ↓ プロフィール・固定投稿・投稿末尾CTA
無料note（あるあるの深掘り＋実用Tips）
  ↓ 記事内導線
有料note（体系化されたノウハウ・テンプレート集）
```

## 7. 当面のKPI（立ち上げフェーズ・仮設定）

| 指標 | 3ヶ月目標 | 備考 |
|------|-----------|------|
| 投稿頻度 | 週3本以上を継続 | まず継続の仕組みを優先 |
| 保存・シェアされる投稿 | 月2本以上 | 共感の質の指標 |
| note流入 | 導線設置と計測開始 | 数値目標はリサーチ後に設定 |
