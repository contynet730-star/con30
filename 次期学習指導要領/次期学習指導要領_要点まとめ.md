# 次期学習指導要領 要点まとめ（学習用）

**基準：論点整理（令和7年9月25日）及び最新の審議状況**
最終更新：令和8年（2026）7月／出典末尾

---

## 1　スケジュール（令和9年度改訂を念頭に）

| 時期 | 事項 |
|---|---|
| 令和6年12月25日 | 文科大臣が中教審に**諮問**（初等中等教育における教育課程の基準等の在り方について） |
| **令和7年9月25日** | 教育課程企画特別部会「**論点整理**」公表 |
| 令和8年度中（2026） | **答申**の取りまとめ予定 |
| **令和9年度中（2027）** | **告示**予定 |
| 令和9年度〜 | **移行期間**（周知・先行実施） |
| 令和12年度（2030） | **小学校 全面実施** |
| 令和13年度（2031） | **中学校 全面実施**（高校は年次進行） |

- 前回（平成29・30年告示）と同様の**約10年周期**。
- **令和9年度＝告示の年。移行期間の初動**として、区・各校は準備を本格化させる。

## 2　改訂の3つの基本的方向性（論点整理の骨格）

1. **質の高い教育の実現** … 「主体的・対話的で深い学び」の"実装"。**コア概念の深い理解**と**複雑な問題の解決**を軸に、各教科の目標・内容を**構造的に見直す**。
2. **多様性の包摂** … 一人ひとりの可能性を引き出す。義務教育に**「調整授業時数制度（仮称）」**を創設し標準授業時数を弾力化。高校教育課程の柔軟化。特別な配慮を要する子への枠組み。
3. **実現可能性（持続可能性）の確保** … 教師の過度な負担を防ぎ、**「余白」**を生む持続可能な制度設計。

## 3　現場に効く主要論点

- **カリキュラム・オーバーロードの解消**：標準授業時数の弾力化（調整授業時数制度・仮称）、内容の重点化・精選、**「教科書『を』教える」から「教科書『で』教える」へ**。
- **情報教育の抜本強化（系統化）**
  - 小学校：総合的な学習の時間に**「情報の領域（仮称）」**を付加。
  - 中学校：技術・家庭科を分離し、**「家庭科」＋「情報・技術科（仮称）」**を創設。
- **生成AI／DX**：生成AIが読み取りやすい形で指導要領をデータ提供し、指導案作成を支援。**情報活用能力を学習の基盤**に位置づけ。
- **個別最適な学びと協働的な学びの一体的充実**：GIGA端末の日常活用を前提に継続・発展。
- **ウェルビーイング**：児童生徒・教職員双方を重視。
- **評価改革**：評価方法（観点別評価等）の見直しを検討。
- **継続する土台**：資質・能力の三つの柱／社会に開かれた教育課程／カリキュラム・マネジメント。

## 4　指導主事としての着眼点（区の準備）

- 「決め打ち」を避ける：**仮称・検討中**の制度・教科名称が多く、**答申・告示で確定**する。
- 「先取り」は方向性のみ：**深い学びへの授業改善・情報活用能力・端末活用**は現行課程でも今すぐ強化できる＝最良の準備。
- **働き方改革と一体**：「余白」の創出、行事・内容の精選を区として後押しする。
