## 凡例・本記録の性格について

本記録は、会場音声の自動文字起こしデータを基に再構成したものです。原データは認識精度が低く、固有名詞・数値・語尾に多数の誤変換が含まれていました。したがって **完全な逐語録ではなく、「聞き取り可能な範囲での準逐語録」** です。取扱いに際しては以下にご留意ください。

| 表記 | 意味 |
| --- | --- |
| （地の文） | 音源から発言内容が確認できる部分 |
| 〔　〕 | 文脈から補った語、または誤変換を訂正した語（推定を含む） |
| 〔聴取不能〕 | 復元できなかった部分 |
| ※注 | 記録者による補足 |

- 数値（調査結果のパーセンテージ等）は誤認識の可能性が高いため、**公表資料での確認を推奨**します。
- 固有名詞の表記ゆれについては、末尾の「確認を要する事項」に一覧化しました。
- 議事録（要旨）は発言順ではなく、**論点ごとに整理**しています。逐語録は発言順のままです。

# 第1部　議事録（要旨）

## 1. 紺多 指導主事　― 5時間目の授業について

### (1) 冒頭

- 昨年12月に旭丘小学校を訪問指導。本校（未来青空学園）を訪問できることを楽しみにしてきた。
- 昨年度は小学校の授業のみだったが、本日は中学部の授業も参観でき、有意義な1日となった。
- 学期開始直後で大雨等もある中、授業準備をいただいたことへの謝辞。
- 講評対象：5時間目に授業公開した **塚本先生（外国語）／田口先生（道徳）／〔　〕先生（水泳）** の3授業。

### (2) 話の柱（三本柱）

**① 全国学力・学習状況調査（質問紙）から見える現状**

- 全国的には、小学校から中学校にかけて**肯定的回答が下がる項目が多い**。
  - 英語の学習について：小6 66.7% → 中3 51.2%（△15.5ポイント）
  - 「英語の勉強は好きですか」：小6 50.8% → 9年生〔数値聴取不能〕
  - 「自分にはよいところがあると思いますか」：小6 85% → 7年生〔聴取不能〕→ 8年生 約88% → 9年生 約92%
- 本校は**全国の傾向と逆に、学年進行に伴って上昇**しており「驚く結果」。
- 特徴的な項目
  - 「友達と協力して発表しながら課題を解決する」：小6 85.1% → 7年生 92% → 9年生 97.1%
  - 「自分〔の成長〕について考えるのが楽しい」：8〔4〕.4% → 87.2%
  - いずれも**東京都・練馬区の結果を上回る**。
- 開校1年目ではあるが、協働し表現する力は**9年間を通じて確かに育ってきている**と質問紙調査から読み取れる。

**② 3つの指導案に共通していた視点**

本日の3つの指導案すべてに、次の3点が共通して書かれていた。

1. **見通しをもたせること**
2. **違いに応じること**
3. **対話を通して考えを深めること**

**③ 授業ごとの講評**

| 授業 | 講評の要点 |
| --- | --- |
| **水泳（〔　〕先生）** | 講評者自身が保健体育科であり、バタフライは苦手で泳げなかったが、「今日の授業を受ければ自分でも泳げるようになったのでは」と思うほど**質の高い授業**。プールに行く前に教室で時間を取り、活動の説明と**映像資料**でしっかり見通しをもたせたことが大きい。展開の中では**教え合う姿**が見られ、「もう少し強くやった方がいい」など**具体的な助言**が交わされていた。クロールは小学校で経験があるがバタフライは経験の少ない子が多く、**スタートラインがそろっている**ことで苦手な子も安心して取り組める設計になっていた。 |
| **道徳（田口先生）「ついていい嘘・いけない嘘」** | 授業の初めに見通しをもたせ、自分が何をするのかを見通して取り組めていた。子供たちが**自然に話し合い活動**をしていた。安心できる環境の中で学習していた。当初「ついていい嘘もある」と書いていた児童生徒が、**振り返りでは「ついてはいけない」と変容**しており、**対話を通じた自己の考えの変容**が見て取れた。 |
| **外国語（塚本先生）** | **ファイナルゴール**を示して見通しをもたせていた。新出表現について**ただ発音させるのではなく、様々な方法を工夫**して発音の機会を多く確保。結果として子供たちが**自信をもって発音**できるようになっていた。**ペア活動**を大事にすることで、どの子も安心して取り組めていた。 |

### (3) まとめ

- 3人とも、**子供たちの差を埋めるのではなく、差を前提に授業を設定**していた。
- そのことによって育てているのは **自己肯定感** と **自己調整（力）**。
- 教師が一方的に管理するのではなく、**ハンドルを子供に委ねていく**ことを今後も大切にしてほしい。
- 「見通し」「違いに応じる」「対話」の3視点は、多くの先生方が意識している部分と重なる。**9年間の学校生活の中でつないでいってほしい**。
- 教科は違えども同じ3視点で授業を捉えられる。だからこそ本日の協議会も**教科を越えて話し合うことができた**。これは**小中一貫教育校だからこそできること**。
- 締めくくり：協議会で小学部・中学部の教員が同じテーマで話し合えるのは他校にはないこと。今後も大事にしてほしい。

## 2. 松澤 指導主事　― 中学部（7・8・9年生）の授業について

### (1) 視点の設定

本校の**目指す学校像のキーワード「ときめき・ひらめき・きらめき」**を自分なりに解釈し、授業を見る視点として設定した。

| キーワード | 授業を見る視点 |
| --- | --- |
| **ときめき** | 生徒が前向きに参加しているか／学習への興味・関心を引き出しているか／挑戦する場面になっているか |
| **ひらめき** | 自分で考える場面はあるか／理由を考える場面はあるか／「分かった・できた」を実感できているか |
| **きらめき** | 誰もが参加できるか／いろいろな考えが認められているか／よさが生かされているか（例：教師が生徒の発言を価値付ける） |

※ 本日は7・8・9年生の参観が中心だったが、途中で1〜6年生の授業も参観した。スライドは中学部向けだが、小学部の先生方にもぜひ見てほしい。

### (2) 授業ごとの講評（時間順）

**◆ 3時間目**

- **〔阿〕〔　〕先生（7年生・数学）** … 「今日どこからだっけ、どこから始める？」という**自然な声かけ**で始まり、生徒が普通に返す。**言葉のやりとりから関係性ができている**ことが分かった。学年で統一した**振り返りシート**を使用しており、学習の軌跡・積み重ねが分かって非常に分かりやすい。
- **〔い〕〔　〕先生** … 参観者が入った瞬間、生徒がそわそわしていたが、先生が「〇〇さんを見に来たんだよ」と**優しく声をかけて**いた。関係性が取れており、**入った瞬間の雰囲気がよく**、生徒が安心して授業に臨めている。途中も進捗を確認し、様子を見ながら進めていた。
- **〔大〕〔　〕先生（英語）** … 生徒が積極的に発言する場面が多く、教師が「うんうん」と受け止め、**生徒が話しやすい雰囲気**を作る工夫。板書は左側が "There is"（1つだから）、右側が "There are"。**教材にマスキングテープを使用**しているのは初めて見た。工夫されている。
- **〔田島〕先生** … 電子黒板を活用。**机間巡視**で様子を見ながら指導。ワークシートについて「**まず埋めることが大事だからね**」と、今何をやればよいかを明確に示し、目標をもたせて進めていた。
- **小林先生（音楽）** … 言葉を添えながら「ここ見るんだよ」と大きな〔教具〕を使って**注視させる指導**。伴奏が途中で止まった際も、すぐに駆けつけてフォロー。3時間目の最後には「**声に心の気持ちが現れるんだ**」「気持ちが〔沈んで〕いると声がちょっと不安になっちゃうね」と、生徒のやる気スイッチを引き出す工夫。加えて、「座っていいよ」と言われた生徒が「**失礼します**」と言って着席しており、**規律がしっかりしている**と感心した。

**◆ 4時間目**

- **〔　〕先生（理科）** … **実験結果をもとにした協働的な学び**。ワークシートで生徒が自分たちで進め、実験結果を照らし合わせるところから**考察して答えを導く**場面が見られた。
- **塚〔本〕先生（社会）** … ドイツとイギリスの対立をテーマに、**タブレットを使って思考を手助け**しながら話し合い。**子供たちの考えを俯瞰させる**授業。
- **岡田先生** … 参観時は話し合いの後半だったため、最後にもう一度戻って参観。**個人で考える時間 → グループで話し合い**という流れで、生徒の意見に耳を傾ける様子が印象的。最後にある生徒が「**世界は少しのことで壊れてしまうんだよ**」とボソッとつぶやき、先生が「うんうん」と受け止めていた。**なかなか出ない発言を拾ってくれる**ことで、生徒が安心していろいろなことを表現できると学んだ。
- **T1・T2による2人体制の授業** … **学習センター〔掲示〕**により、何をやればよいかが上を見れば分かるよう**可視化**されていた。T1が説明する際、T2は「うんうん」と聞きながら見守り、「じゃあやってください」となった時点で**聞き漏らした生徒のところに寄ってフォロー**する役割分担ができていた。
- **〔　〕先生（数学・5時間目の研究授業〔にも参加〕）** … 「用意スタート」で5分間の取組。**一人一人ワークシートが違い**、2年生相当の子も3年生相当の子もいるなど、**個に応じたワークシート**を作成していた。5分のうち2分半ほど参観したが本当に集中しており、「50分の授業の中でこれだけ全集中している時間があるのは素敵だ」と感じた。

### (3) 結び

時間になったので、本日は小学部の先生も含め、授業を公開いただいた先生方に感謝。

## 3. 都丸 指導主事　― 全体講評（社会の変化と小中一貫教育の意義）

### (1) 導入クイズ「250万年」

- 「これは何の数字だと思いますか」と会場に問いかけ。答えは **250万年**。
- **Society 1.0〜5.0** の各段階が続いた期間の話（諸説あり）。
  - 狩猟社会（1.0）：約250万年
  - 農耕社会（2.0）：約1万年
  - 工業社会（3.0）：約200年
  - 情報社会（4.0／インターネットの普及）：約50年
- 変化のスピードが加速している。**Society 5.0 ではどうなるのか**を考えさせられる。

### (2) 「14年前」と「14年後」

- **14年前（2012年頃）** を思い出してほしい。ガラケーには赤外線通信が付いていた。スマホが出始めた頃。iPodを持っている人がかっこいいと思っていた。**懐かしいと同時に、今とこんなにも違うのかと驚く**。
- 同じ視点で **14年後（2040年頃）** はどうなるか。スマートウォッチすらも変わっているかもしれない。
- 生成AIに聞いてみた予測として、街の完全無人化・無人コンビニ、インフラ〔の自動化〕、医療の発展〔による健康管理〕などが挙がる。

### (3) なぜこの話をするのか ― 学習指導要領と2040年

- **今年度中に次期学習指導要領の答申が出て、来年度以降が移行期間**となる。学習指導要領の「賞味期限」は約10年であり、**ちょうど14年後の社会を想定して、どんな力を付けさせるべきかを今まさに話し合って作っている**のが次期学習指導要領である。
- 経済産業省の推計（2040年頃）
  - **職業のミスマッチ**：専門職やAI・ロボット等を扱う人材は**不足**。一方で事務的な役割の人材は**約437万人が過剰**。
  - **学歴のミスマッチ**：普通科の子が余り、工業科等の需要が高まる。文系の大学が余る。現に理系に予算が投じられ、大学が理系にシフトしている。
- 大学が変われば高校が変わり、中学校・小学校も変わらざるを得ない。**先を見据えて変わっていく**というのが本日伝えたいこと。
- プログラミング教育の必修化、算数・数学における「データの活用」の導入。今後は**生成AIの活用**も学習指導要領に位置付けられ、学校現場に入ってくる。
- **小中一貫教育校も「先があるから今こうしなければならない」という考えをもつ必要がある。**

### (4) 学校教育目標の「人」という言葉

- 目標は**2年間かけて**、令和6年度から部会を作り、坂本校長先生をはじめ多くの方に参画いただいて策定した。当初の文言は全く違っていた。
- **最大のポイントは最後の言葉「人」**。当初は「児童・生徒」だった。
- 検討の場で三田先生〔要確認〕から「**児童を育てる・生徒を育てるではなく、その先に、私たちは"人"を育てるのではないか**」という発言があり、これを受けて「人」となった。
- したがって、目指すのは**15歳のゴールではなく、15歳になった人がさらに力を磨き、伸ばし、社会に貢献していく姿**。
- **中学部だけが目指すものではなく、小学部・中学部が9年間かけて目指すもの**である。

### (5) 子供たちへのインタビューから

策定に2年間関わってきた立場として、**子供たちがどう思っているか**が気になり、給食の時間等に直接話を聞いた。

**◆ 小中一貫のよさを感じた2つの場面**

1. **教員間の実態共有** … 研究授業の風景の中に、有山先生と大村先生が水泳の授業について話している場面があった。大村先生が「小学校で顔をつける実態」（早い子・遅い子と学年の実態）を話しており、それは**中学校の指導にも生かせる実態情報**。こうしたことが日常の研究の中で行われ、「小6＋中3」ではなく「**9年間**」で捉えられているのがよい。
2. **小学部の先生の存在** … 五十嵐先生が中学部の授業を見に行った場面に居合わせた。子供たちがニヤニヤして安心した雰囲気だった。中学部の生徒にとって**小さい頃から知っている小学部の先生**は大きな存在。**利害関係のない相談相手**として小学部の先生に相談できる環境がある。逆に小学部の先生も、中学校の世界を知っている先生に相談できる。**引き継ぎでは伴走支援と共有ができる**環境である。

**◆ 児童・生徒の声**

| 立場 | 発言者 | 内容 |
| --- | --- | --- |
| 下級生の視点 | 6年生・川島さん | 姉がいて中学部と一緒なのは気まずい。運動会などが合同で**自分たちの時間が少なくなった**。ただし「**運動会の中学生の演技はすごくよかった／迫力があった**」 |
| 上級生の視点 | 7年生・笠原君 | 「運動会で〔応援等を〕できたのがよかった」。**去年の自分と重ねて、自分が成長できた実感がある** |
| 上級生の視点 | 7年生・吉田君 | 運動会もよかった。合唱では「**自分たちが一番下じゃない。一番下には1年生がいるから頑張らなきゃいけない**」 |
| 生徒会長 | 松宮さん（岡田先生の協力による） | 「**全校の人数が増えたと感じられるようになった**」「授業で一緒になったときに、**小学生の意見がすごく面白くて新しい発見**になった」 |

### (6) 今後への提案

- **知人（高校国語科教員）の例** … 高校では入試・学習の内容が変わり、**自分のことをプレゼンで書く**機会が増えている。そのため「作文の指導は小学生のうちからしてあげなければ」と考え、小学生への作文指導を行っている。
- 同様に、**15歳＝義務教育の出口を知っている中学部の教員が、前期段階の子供たちに「ゴールはこうだよ」と示す**ことができる。作文指導などを題材に、**小中の交流**が生まれるとよい。
- **教員同士が授業を見合う機会**がもっと増えるとよい。
- 運動会等は実施後にアンケートを取り、次年度の在り方を検討していると聞いている。**合同で行いながらも、それぞれのよさを生かす部分をどうするか**を、児童・生徒のアンケートを取りながら今後も検討して進めてほしい。
- 今後も支援していく。

## 1. 紺多 指導主事

> 〔司会〕　午後〔5時間目〕の授業について、紺多指導主事よりお話いただきます。よろしくお願いいたします。

改めましてこんにちは。〔指導課〕の紺多でございます。

私自身、昨年の12月に旭丘小学校の〔訪問指導〕をさせていただき、今日、未来青空学園に来ることができたというところで、すごく、先生方の授業を見ることを楽しみにしてまいりました。昨年度は小学校の授業〔だけ〕だったんですが、今日はこれプラス中学部の先生方の授業を見られるということで、1日、有〔意義〕な時間を過ごすことができました。本当にありがとうございました。

また、学期が始まって、大雨〔など〕であったりとか、いろいろある中で、授業準備等を〔してくださいまして〕ありがとうございます。

私からは〔投影〕資料を使って、5時間目に授業をしてくださった塚本先生、田口先生、〔　〕先生の授業について、短い時間ですが、私が指導講評という形でお話しさせていただきたいと思います。
