# 石川移住シナリオ：持ち家売却・教員再就職・農業の組み合わせ比較

作成日：2026年9月21日

**前提**
- 次男45歳／東京都の公立小学校教員／年収約900万円／**農業経験ゼロ**
- 配偶者／年収約800万円（**世帯 約1,700万円**）
- 持ち家：東京都練馬区早宮4丁目の一戸建て（売却を検討）
- 承継先：農事組合法人 紺多農園（白山市末正町）
- 検討中：①石川県の正規教員に再就職 ②非常勤教員 週3〜4日＋農業

---

## 0. 結論

**この構成は、前回試算（「退職して専業農家」＝年収200〜300万円）とは別物です。世帯収入を大きく落とさずに承継できる道があります。**

ただし、**決定的な法的制約が1つあります。**

> **正規の公立学校教員のままでは、農事組合法人の理事に就任できません。**
> 営利企業の役員兼業は、名義だけであっても兼業に該当し、禁止されます。地方公務員の兼業許可基準は「兼業先が**非営利団体**であること」を要件に挙げており、農事組合法人はこれに当たりません。
>
> **一方、非常勤講師（パートタイム会計年度任用職員）は地方公務員法第38条（営利企業への従事等の制限）の適用除外**であり、理事就任が可能です（自治体により届出が必要）。

**つまり「正規教員＋週末農業」では"継げません"。手伝えるだけです。**
承継するなら、**どちらか一方が非常勤になる必要があります。**

**→ 推奨は、夫婦で役割を分ける案C（配偶者が正規教員、次男が非常勤＋農業）です。**

## 1. 練馬の家は、この計画の最大の資産です

### 土地単価の差が圧倒的です

| 地域 | 坪単価（2026年） |
|---|---|
| **練馬区早宮4丁目**（公示地価） | **162.66万円/坪**（49.2万円/㎡） |
| 参考：早宮2丁目 | 235.3万円/坪 |
| 参考：早宮3丁目 | 183.2万円/坪 |
| **白山市**（2026年平均） | **約17.3万〜19.4万円/坪** |

**約8.4〜9.4倍の差**です。

### 売却額の目安

敷地面積が不明なため、練馬の戸建の一般的な規模で置きます（**実測が必要です**）。

| 敷地 | 土地値の目安 |
|---|---|
| 30坪 | 約4,880万円 |
| 35坪 | 約5,690万円 |
| 40坪 | 約6,510万円 |

建物は築年数次第でほぼ評価ゼロ〜数百万円。実勢価格は公示地価の1.0〜1.2倍程度になることが多いです。

### 白山市側の住居費

- 白山市・松任駅周辺の中古戸建の例：**1,949万円（4SLDK、リフォーム費込み）**
- **末正町に実家があるなら、住居費は実質ゼロになる可能性があります**

**差し引き、3,000万〜6,500万円の現金が手元に残る計算です。これは年収差200〜300万円を20年以上吸収できる規模です。**

### 税務上の重要ポイント（要確認）

マイホームを売った場合、**「居住用財産を譲渡した場合の3,000万円の特別控除」**が使えます。所有期間10年超なら**軽減税率の特例**も併用できる場合があります。
→ **売却前に税理士に確認してください。順番を間違えると数百万円単位で変わります。**

### 売らずに貸す選択肢も検討の価値があります
練馬区・平和台エリアは賃貸需要が堅い地域です。ただし遠隔地からの賃貸管理の手間と、3,000万円特別控除が使えなくなる点（賃貸に出すと居住用でなくなる）を天秤にかけてください。

### ローン残債の確認が先です
**残債がわからないと、この試算は成立しません。** まず残高証明を取ってください。

## 2. 石川県の教員に再就職した場合の年収

### 良いニュース：給与の号給は引き継げます

**前歴加算10割**のため、これまでの勤続年数の号給からスタートできます。ゼロからやり直しではありません。

また、**現職教員は第1次選考の全部または一部が免除されるケースがあります**（小学校教員を含む）。在職のまま受験することも可能です。

### 悪いニュース：石川県の教員給与は全国最下位です

| 都道府県 | 平均給与（月額） |
|---|---|
| 東京都 | **43万9,290円**（全国1位） |
| 石川県 | **39万0,730円**（全国**最下位**） |
| 差 | **約4万9,000円/月** |

東京都は諸手当が月9万8,104円と突出し、うち**地域手当が月7万0,623円**（全国1位）。この地域手当が石川県では消えます。

### 年収の推定

| | 東京都（現在） | 石川県（推定） | 差 |
|---|---|---|---|
| 次男 | 900万円 | **730〜780万円** | ▲120〜170万円 |
| 配偶者 | 800万円 | **650〜700万円** | ▲100〜150万円 |
| **世帯** | **1,700万円** | **1,380〜1,480万円** | **▲220〜320万円** |

※ 月額差と地域手当の消失が賞与にも跳ねるため、実際の減少幅はこのレンジの上限寄りになる可能性があります。**石川県教育委員会の給与条例で個別試算を取ってください。**

### 退職手当と年金は、心配が要りません

- **退職手当**：退職後に引き続き公務員として再就職し、勤続期間を**通算**する選択をすれば、元の自治体からは支給されず、期間が引き継がれます。**受け取るか継続するかを選べます**
- **年金**：一元化後は厚生年金なので、都道府県をまたいでも**当然に通算**されます

**→ 前回試算で最大の懸念だった「45歳で厚生年金を抜けると生涯2,000万円超の損失」は、教員を続ける限り発生しません。これは非常に大きい。**

## 3. 非常勤講師の場合

| 項目 | 内容 |
|---|---|
| 時給 | **2,000〜3,500円程度**（自治体・職種による） |
| 年収の実例 | 週3.5日勤務で**年収300万円超**／週3日午前のみで月17万円／週10時間で年約130万円 |
| 社会保険 | **週20時間以上＋月額8.8万円以上＋1年以上の任用見込み**で健康保険・厚生年金に加入可能 |
| **兼業** | **パートタイム会計年度任用職員は地方公務員法第38条の適用除外**。営利企業従事制限がかからない（自治体により届出が必要） |

**週3〜4日なら年収250〜400万円、かつ厚生年金を維持できる可能性が高い**構成です。

**注意：複数校・複数自治体にまたがる勤務だと社会保険に加入させてもらえないケースが報告されています。** 1校でまとまった時間数を確保できるかが分かれ目です。採用時に必ず確認してください。

## 4. シナリオ比較（世帯ベース）

| | 案A 二人とも正規教員 | 案B 二人とも非常勤＋農業 | **案C 配偶者=正規／次男=非常勤＋農業** |
|---|---|---|---|
| 次男の収入 | 730〜780万円 | 250〜300万円 | **250〜300万円** |
| 配偶者の収入 | 650〜700万円 | 250〜300万円 | **650〜700万円** |
| 経営開始資金 | ー（対象外の可能性大） | 150万円×3年 | **150万円×3年** |
| 農業所得 | ー（無報酬の手伝いのみ） | 100〜300万円 | **100〜200万円** |
| **世帯合計** | **1,380〜1,480万円** | **750〜1,050万円** | **1,150〜1,350万円** |
| **理事に就任できるか** | **✗ できない** | ○ できる | **○ できる** |
| **＝承継できるか** | **✗ 手伝えるだけ** | ○ | **○** |
| 社会保険・退職手当 | ◎ 二人とも万全 | △ 条件次第 | **○ 配偶者側が土台** |
| 農業に使える時間 | 週末・長期休暇のみ | 週4〜5日×2人 | **週4日** |
| リスク | 承継が実現しない | 収入が大きく落ちる | **バランス** |

### 案Aの致命的な欠陥

**収入は最も高いのに、「継ぐ」という目的を達成できません。**

正規教員のままでは農事組合法人の理事になれないため、組合員として無報酬で手伝うことしかできません。代表理事にもなれません。認定新規就農者の要件である「経営の主宰権」も持てず、**経営開始資金（最大450万円）の対象からも外れます**。

**「石川の教員に戻って週末に農業」は、農園を継ぐ計画としては成立しません。**（ただし、親御さんが現役を続けられる間の"つなぎ"としては有効です。）

### 案Cを推奨する理由

1. **配偶者の正規教員が、社会保険・退職手当・年金・安定収入の土台を担う**
2. **次男は非常勤なので兼業規制がかからず、理事就任・経営主宰が可能**
3. **週4日を農業に充てられるので、農民要件と認定新規就農者の要件を満たせる**
4. **経営開始資金（年150万円×3年）を取れる**
5. **世帯1,150〜1,350万円**は、現状1,700万円から▲350〜550万円。**練馬の売却益3,000〜6,500万円が完全に吸収します**
6. 万一農業が合わなければ、次男が正規教員に戻る道が残る（**可逆性がある**）

**唯一の懸念は、次男の非常勤の年金・退職金が薄くなることです。** ただし週20時間以上で厚生年金に加入できれば、大きな穴にはなりません。

## 5. 時間軸（45歳→49歳の4年で組み立てる）

経営開始資金の**49歳以下**要件があるため、逆算が必要です。

| 時期 | 次男 | 配偶者 | 家 |
|---|---|---|---|
| **今〜1年**（45〜46歳） | 在職のまま。長期休暇に**無報酬で**農作業／決算書3期分を確認／北辰農産に話を聞く | 在職 | **ローン残債・敷地面積を確認**／税理士に3,000万円特別控除を相談 |
| **1〜2年目**（46〜47歳） | 石川県の教員採用選考を受験（現職者は1次免除の可能性）／白山市農業振興課に相談 | **石川県の採用選考を受験** | 売却の段取り |
| **2〜3年目**（47〜48歳） | 移住。**非常勤講師**として勤務開始／農作業に週4日／認定新規就農者の申請 | **石川県で正規教員として勤務開始** | 練馬売却・白山市に転居 |
| **3〜4年目**（48〜49歳） | **組合員加入 → 理事就任**／**経営開始資金の受給開始** | 継続 | ー |
| **5年目以降** | 代表理事へ／有機・特栽転換／学校給食・食育 | 継続 | ー |

**ポイント：配偶者が先に石川県の正規教員のポジションを確保してから、次男が非常勤に移る**のが安全な順序です。世帯の土台を先に作ります。

## 6. 「元小学校教員が有機農業をやる」の価値（再掲・重要）

白山市は**オーガニックビレッジ宣言**を行い、**学校給食への有機農産物供給**を進めています。しかもこれは第2次白山市教育振興基本計画の重点取組**「はくさん3育（ジオ育・食育・読育）」**に位置づけられています。

**次男が非常勤講師として学校現場に週3日いながら、有機農産物を給食に納め、食育の授業もできる。**

これは白山市の政策そのものです。他の農家には絶対に真似できません。そして**非常勤講師という立場は、この戦略においてマイナスではなく、むしろ最強の営業ポジションです。**

配偶者が正規教員であることも、学校現場とのつながりという意味で効きます。

## 本資料の制約

- 敷地面積・ローン残債・紺多農園の経営数値がいずれも未確認のため、**すべて目安です**
- 本作業環境のネットワークポリシーにより外部サイトへの直接アクセスが遮断されており、**検索エンジン経由の情報のみ**で作成しています
- **兼業の可否、選考区分、退職手当の通算、税の特例は、いずれも個別事情と自治体の運用で変わります。必ず一次窓口で確認してください**
- 特に**「正規教員は農事組合法人の理事になれない」**という点は、本資料で最も重要な結論であると同時に、**任命権者の判断に委ねられる部分があります。石川県教育委員会の服務担当に直接確認することを強く勧めます**
