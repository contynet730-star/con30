# PART 2　結論は5つ

## 結論1　コメは稼げない。しかしやめる必要もない

- 2026年産の概算金は**1.5万〜1.8万円**に対し、コスト指標は**玄米60kgあたり20,535円**。**逆ざや＝作るほど赤字**
- 石川県産コシヒカリの店頭価格は5kgで4,780円→2,980円（約4割安）
- 生産者の85%が「厳しい」、25%が「経営継続に強い不安」
- **ただし面積と機械は既にある。2027年度からは主食用米にも環境配慮の交付金がつく**

→ **コメの役割は「稼ぐ」から「面積を維持して交付金を取る土台」に変わった。**

## 結論2　稼ぎ頭は「たまねぎ」。ブロッコリーとの二本柱

5人のプロの視点（青果卸／普及指導員／経営コンサル／大規模生産者／行政JA）で分析した結果です。

- **野菜需要の約6割は加工・業務用。国産シェアは68%で、32%が輸入に流出**。ここが唯一の空白マーケット
- 加工・業務用の契約栽培は「定時・定量・定質・**定価**」を求められる＝**価格が事前に決まる。米価暴落の世界から抜け出せる**
- **加工・業務用向けは10aあたり15万円の定額助成**（国産野菜周年安定供給強化事業）。たまねぎの10a所得11.1万円に上乗せで**実質26万円**
- **JAとなみ野（富山）が機械のリース方式で産地化に成功し、販売2億円超**。隣県・同じ北陸・同じ水田転換畑の再現可能な事例
- **水稲・たまねぎ・ブロッコリーは作期がほぼ重ならない**（たまねぎは秋定植→初夏収穫）
- たまねぎはヒガンバナ科で、**ブロッコリー（アブラナ科）と輪作が成立する**

**キャベツは却下。** ブロッコリーと同じアブラナ科で連作障害・病害虫を共有するため、輪作になりません。地域に産地もなく、大産地が相場を握っています。

**たまねぎの弱点（正直に）：** 湿害に弱く20cm以上の高畝と暗渠が必須。機械の単独購入は非現実的で、JA・近隣法人との共同利用が前提。**この2つが解けないなら見送り、ブロッコリーの作期分散と有機化に集中すべきです。**

## 結論3　お兄様が主体なら、次男の兼業問題は発生しない

**週末に無報酬で手伝う分には、副業（兼業）になりません。許可も不要です。**

守るべき線は3つだけ。

1. **報酬を受け取らない**（地方公務員法38条。実家の手伝いでも報酬をもらえば違反）
2. **組合員・理事にならない**（役員兼業は名義だけでも禁止）
3. **「自営」の規模を超えない**（耕地30a未満かつ年販50万円未満なら許可不要。ただし法人が経営主体なら、そもそも自営に当たらない）

→ **これで「夫婦とも石川県の正規教員＋週末手伝い」が成立します（案D）。**

## 結論4　移住しても世帯収入は▲220〜320万円で済む

- **石川県の教員採用試験は年齢制限が60歳未満**に緩和済み。45歳・47歳とも受験可能
- **前歴加算10割**で号給を引き継げる。**退職手当も通算を選べる**。厚生年金は当然に通算
- ただし石川県の教員給与は全国最下位（月39.1万円 vs 東京43.9万円）。地域手当7.06万円の消失が主因

| | 現在 | 移住後（案D） |
|---|---|---|
| 次男 | 900万円 | 730〜780万円 |
| 配偶者 | 800万円 | 650〜700万円 |
| **世帯** | **1,700万円** | **1,380〜1,480万円** |

**差は▲220〜320万円。資産8,000万〜1億1,800万円で、25〜50年分吸収できます。** しかも移住で生活費自体が下がります。

## 結論5　資産があることが、最大の競争優位

**多くの農家が有機や高付加価値化に踏み切れないのは、転換期の谷で資金が尽きるからです。** 有機JASは転換に3年かかり、その間は収量が落ち、除草労力が増え、認証はまだ取れない。ここでほとんどが引き返します。

**紺多農園はその谷を越えられます。** これが他の誰も持てない優位性です。

→ **「農業で年収900万円を取り戻す」必要はありません。** 資産が生活を支える間に、10年かけて有機・ブランド化・6次産業化という時間のかかる正攻法を選べます。

## フェーズ3　5〜10年（2031〜2036）　**多層化する**

```
第1層  コメ         面積と機械を維持。交付金とクレジットで支える（薄利）
第2層  たまねぎ      加工・業務用の契約栽培。価格が読める収益の柱

第4層  加工・直販・体験  北辰農産モデル。米を米として売らない
```

**この四層なら、米価が暴落しても、たまねぎ相場が崩れても、全部が同時に倒れることはありません。**

**これは「大規模化」ではなく「多層化」です。** 面積の勝負では安井ファームにも集落営農法人にも勝てません。勝てるのは、**水田と園芸と教育（食育）を一つの経営体で束ねられる**という、紺多農園にしかない組み合わせです。

# PART 4　やらないこと

はっきり「やらない」と決めておくべきものです。

| | 理由 |
|---|---|
| **キャベツ** | ブロッコリーと同じアブラナ科。連作障害・病害虫を共有し輪作にならない。地域に産地もない |
| **ドローン（当面）** | 有機・減農薬の方向と逆。委託なら1ha 2〜3万円で済む。資格が四重に必要（二等無人航空機操縦士＋機体認証＋メーカー認定＋農薬散布認定）。買うのは**みどり認定を取った後**、経営掌握3年後、受託で稼ぐ目算ができてから |
| **面積だけの大規模化** | コスト率には**15〜20haと25〜30haに二つの谷**があり、**20〜25haが最も非効率**。米価下落で最も危ないのは規模拡大した担い手。2026年1〜8月の米作農業の廃業28件＋倒産4件 |
| **次男が正規教員のまま理事になる** | 役員兼業は名義だけでも禁止。**不可能**。お兄様が主体なら問題は発生しない |
| **投資信託の取り崩しで農業の赤字を埋める** | NISAの非課税枠は復元に時間がかかる。**現金クッションで吸収する**。預金231万円は薄すぎるので、練馬の売却益で生活費2年分（1,000万円程度）を現金化 |
| **法人の資金と個人資産を混ぜる** | 出資は出資、貸付は貸付として書面で分ける。既存借入への**個人保証の有無を必ず確認** |
