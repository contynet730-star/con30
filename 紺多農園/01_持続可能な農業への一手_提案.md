# 紺多農園 持続可能な農業への「一手」提案書

作成日：2026年9月21日

対象：農事組合法人 紺多農園（石川県白山市末正町エ10番地／法人番号 1220005008354／2019年2月設立）
作付：水稲、ブロッコリー、野菜

---

## 0. 結論（先に一手）

**「特別栽培（化学肥料・化学合成農薬5割減）＋緑肥」を全圃場の標準にし、白山市のオーガニックビレッジに生産者として手を挙げる。**

これを2026年度中（＝2027年産の作付計画を決める前）に動かす。理由は3つ重なっているからです。

1. **米価が落ちた。** 石川県産コシヒカリの店頭価格は5kgで2025年の4,780円から2026年は2,980円へ、約4割安。概算金もJA石川県中央会が「前年（30,000円台）を下回る見通し」としています。慣行栽培の主食用米で数量を追う戦略は、今期から急速に苦しくなります。
2. **白山市が有機に舵を切った。** 白山市は「オーガニックビレッジ宣言」を行い、令和7〜11年度の5年計画「白山市有機農業実施計画」を策定済み。学校給食への有機米供給も動いています。JA白山も令和6年度から子会社（有）アグリサポート白山で特別栽培米「ひゃくまん穀」、令和7年度から有機野菜の実証に入り、**栽培マニュアルを作って管内生産者へ普及し「仲間づくりと産地化」を目指す**と明言しています。つまり、**受け皿が先にできていて、生産者を探している状態**です。
3. **2027年度から国の水田政策が変わる。** 水田活用の直接支払交付金が見直され、5年に一度の水張り要件は廃止。田畑を問わず作物ごとの生産性向上を支援する形に転換し、**有機・減農薬・減化学肥料など環境配慮の取組を新たな交付金で支援、主食用米も対象**になります。今から実績を積んでおく農家と、制度が始まってから動く農家で差がつきます。

価格が落ちる局面で単価を守る手段は、①差別化（有機・特栽）、②環境支払い（交付金・クレジット）、③コメ以外の収益源（ブロッコリー）の3つしかありません。この提案は3つ全部に同時に効きます。

---

## 1. なぜ「有機JAS一直線」ではないのか

有機JASは転換期間に原則3年かかり、収量減と除草労力の増加をいきなり背負うことになります。紺多農園の規模と人手が未確認である以上、初手として推奨しません。

一方、**特別栽培（5割減）は環境保全型農業直接支払交付金の交付要件そのもの**です。5割減を満たしたうえで対象取組（緑肥・堆肥・有機農業など）を1つ乗せると交付対象になります。つまり、

- 特栽は**有機への助走路**（転換期間の実質的な準備になる）
- 同時に**その年から交付金と販売単価の両方が取れる**

という二重取りができます。まず特栽で土台を作り、圃場を選んで有機に進む、という順番が安全です。

## 2. 使える制度（金額は目安・要確認）

> 注記：農林水産省・石川県・白山市の公式サイトは本作業環境のネットワーク制限で直接参照できませんでした。以下の数字は検索結果ベースの目安です。**申請前に必ず白山市産業部農業振興課（076-274-9540）とJA白山で確認してください。**

### ① 環境保全型農業直接支払交付金 ★本命
化学肥料・化学合成農薬を原則5割以上低減する取組と合わせて行う営農活動を支援。

| 対象取組（全国共通） | 交付単価の目安 |
|---|---|
| 有機農業 | 14,000円/10a |
| 炭素貯留効果の高い有機農業 | 上記＋2,000円/10a |
| カバークロップ（緑肥） | 5,000円/10a |
| 堆肥の施用 | 3,600円/10a |

- 対象者：本交付金に取り組む**2戸以上の農業者で構成する団体**が基本。一定の条件を満たす農業者（個人・法人）は単独でも対象。
- 令和6年度から交付要件が「環境負荷低減のチェックシート」の取組実施に変更されています。
- **紺多農園は法人なので単独申請の可否をまず確認。難しければJA白山経由で2戸以上の団体を組むのが早道です。**

### ② J-クレジット「水稲栽培における中干し期間の延長」（方法論 AG-005） ★追加投資ゼロ
中干し期間を、その水田の**直近2か年以上の実施日数の平均より7日以上延長**すると、メタン削減分がクレジットとして認証され売却できます。

- 収益目安：**1,000〜3,600円/10a**（地域・排水性・有機物施用量による。クレジット単価は購入者との相対取引）
- 追加の資材も機械も要りません。**水管理の記録だけ**です。
- 技術面：中干しを1週間延長しても収量・タンパク含量に影響しなかったという試験結果がある一方、生育時期をずらすと籾数・収量が減る傾向の報告もあります。**幼穂形成期の3日前までには入水して中干しを終える**こと、メタン削減には**田面に小ひびが入る状態**が必要（砂質土壌ではひびが入りにくい）点に注意。
- 紺多農園がやること：①アグリノート／井関／ヤンマー等のプロジェクト運営・販売事業者に問い合わせ、②**過去2か年の中干し実施日数の記録を圃場ごとに整理**（ここが無いと始まりません）、③2027年産から実施。

### ③ みどり認定（環境負荷低減事業活動実施計画／みどりの食料システム法） ★土台
石川県知事の認定を受けると、計画に沿って導入する機械等について支援措置が受けられます。

- 特別償却：**機械等32％、建物等16％**（設備投資初年度の所得税・法人税が軽くなる）
- 無利子融資、**国の補助事業の優先枠**の申請が可能に
- 令和7年11月末時点で全国31,000経営体超が認定済み。窓口は石川県（農業関連部局）。
- **これは単体で現金が入る制度ではなく、他の補助事業を取りに行くときの「資格」になります。** 機械更新の予定があるなら、その前に取っておくべきです。

### ④ 白山市オーガニックビレッジ／学校給食 ★販路
- 白山市は白山手取川ユネスコ世界ジオパーク認定・SDGs未来都市選定という文脈で有機を推進。
- 学校給食への有機農産物提供が動いており、**市内で安定供給できる生産者が必要**な局面。
- JA白山も白山市と連携して有機農産物の安定供給体制を構築中。
- 学校給食は**数量と価格が読める販路**です。米価下落局面ではこの「読める」ことの価値が非常に大きい。

### ⑤ ブロッコリー：2027年度の水田政策転換を前提に動く
- 白山市はブロッコリーの実質的な主産地です（市内の安井ファームが県内作付面積の約3分の1、年間約200万個を出荷）。出荷ルートと技術情報が地域内にあるのは大きな強み。
- 2027年度から水張り要件が廃止され、畑地化を含めて農地をフルに使う政策に変わります。**ブロッコリー圃場を水田のまま回すか、畑地化して固定するかの判断材料が2026年度中に出そろいます。**
- 判断は2027年度の制度詳細が確定してから。**今は決め打ちせず、圃場ごとの排水性データを取っておくこと**が準備になります。

## 4. 概算：10haの水田で何が変わるか（試算例）

> 紺多農園の実面積は未確認のため、仮に水稲10ha（100,000㎡＝1,000a）として置いた場合の目安です。

| 項目 | 単価 | 10haでの年額 |
|---|---|---|
| 環境保全型（緑肥・カバークロップ） | 5,000円/10a | 500,000円 |
| J-クレジット（中干し7日延長） | 1,000〜3,600円/10a | 100,000〜360,000円 |
| **小計（特栽ベース）** | | **60〜86万円** |
| 環境保全型（有機農業に移行した場合） | 14,000円/10a | 1,400,000円 |

これに**特別栽培・有機による販売単価の上乗せ**が乗ります。米価が5kgあたり1,800円下がる局面で、単価を守る手段を持っているかどうかの差は、この交付金額よりさらに大きくなります。

※ 環境保全型農業直接支払交付金とJ-クレジットの併用可否（長期中干しが交付金の対象取組にも含まれるため、二重取りの制限がある可能性）は**必ず事前確認してください。**

## 5. リスクと注意点

- **中干し延長は無条件に安全ではない。** 幼穂形成期の3日前までに入水を終えること。砂質土壌では田面にひびが入らずメタン削減効果が出ない可能性があります。初年度は全圃場ではなく一部で試すのが妥当です。
- **5割減は除草・防除の労力を確実に増やします。** 人手の裏付けなしに全圃場へ一気に広げない。
- **交付金は「取組を始めてから申請」ではなく事前手続きが必要です。** 作付前の年度内に動く必要があります。
- **2027年度の新水田政策はまだ制度詳細が固まりきっていません。** ブロッコリーの畑地化のような不可逆な判断は、詳細確定を待つべきです。
- 2026年8月の記録的豪雨で収穫間際の水田が被害を受けたと報じられています。気候リスクへの備え（排水対策・作期分散）も持続可能性の一部として並行検討を。
