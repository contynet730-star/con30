# 未経験（農業経験ゼロ）からの就農ルートと、ドローン導入の判断

作成日：2026年9月21日

前提：東京都の公立小学校教員／45歳・次男／**農業経験ゼロ**／本人年収900万円・配偶者800万円

---

## 1. 経験ゼロは、制度上は「想定内」です

国の新規就農支援が**49歳以下**を対象にしているのは、まさに「他産業から未経験で入ってくる人」を担い手として想定しているからです。45歳・経験ゼロは、制度の対象ど真ん中です。

問題は制度ではなく、**時間**です。未経験から経営判断ができるようになるまで、最低3年かかります。そして**45歳から49歳までの4年しか、制度の窓は開いていません。**

## 2. 未経験者が使える2つの資金（合計で最大750万円）

| 制度 | 金額 | 期間 | 主な要件 |
|---|---|---|---|
| **就農準備資金** | 月12.5万円（**年最大150万円**） | **最長2年** | 県が認めた研修機関で**概ね1年以上（年1,200時間以上）**の研修。就農予定時**49歳以下** |
| **経営開始資金** | **年最大150万円** | **最長3年** | **認定新規就農者**であること。就農時**原則49歳以下**。親元就農でも、親の経営が法人なら「5年以内に**法人の経営者になる**」確約で対象 |

**理論上の最大は 300万円＋450万円＝750万円です。**
※ 両制度の通算可否・重複調整は自治体で運用が異なります。**白山市産業部農業振興課（076-274-9540）で必ず確認してください。**

### 研修先の有力候補：いしかわ耕稼塾（本科）

いしかわ農業総合支援機構が運営する新規就農希望者向けコースです。

| 項目 | 内容 |
|---|---|
| 日程 | **週5日（月〜金）8:30〜17:00、約240日/年** |
| 期間 | **1〜2年** |
| 年齢 | 入塾時**60歳未満** |
| 費用 | **研修料無料**（テキスト・大型特殊免許取得費用として3万円程度が自己負担） |
| 実習 | 河北潟試験地での野菜、県研究センターでの水稲・花き・果樹・畜産、**農家派遣研修**、**農業機械研修** |
| 講義 | 作物栽培、土壌肥料、**営農計画作成**、**農業簿記** |

**注意：週5日フルタイムです。教員を続けながらは通えません。** つまり「研修に入る＝退職する」であり、ここが不可逆点になります。

## 3. 未経験ゆえに、順番を間違えてはいけない

### やってはいけない順番
```
退職 → 移住 → 機械を買う → 作り方を覚える
```
未経験者が最も失敗するパターンです。機械は資金を固定化し、判断を誤っても引き返せなくなります。

### 推奨する順番
```
① 辞めずに関与（長期休暇・週末）→ 決算書3期分を見る
② 研修（いしかわ耕稼塾 or 農家派遣）＋ 就農準備資金
③ 組合員加入・認定新規就農者 → 経営開始資金
④ 経営を握る（代表理事）
⑤ 設備投資（ここで初めて機械の話）
```

**第①段階は、公務員のまま可能です。** 地方公務員法第38条により報酬を得る兼業には許可が必要ですが、**無報酬の家業の手伝い（小規模な農業）は許可不要**とされています。**報酬を受け取った瞬間に違反になる**ので、そこだけは厳密に。まず勤務先の服務担当に確認してください。

## 4. 教員のキャリアは、この農園では武器になります

未経験は不利ですが、**小学校教員という経歴は、紺多農園の戦略とほぼ完璧に噛み合います。**

### 理由1：白山市の政策と直結している

白山市は**オーガニックビレッジ宣言**を行い、**学校給食への有機農産物供給**を進めています。しかもこれは第2次白山市教育振興基本計画の重点取組**「はくさん3育（ジオ育・食育・読育）」**に位置づけられています。

**元小学校教員が有機農業をやり、食育の授業で学校に入る。** これは他の農家には絶対に真似できない差別化です。市の担当者にとっても、教育現場の言語が通じる生産者は極めて扱いやすい相手です。

### 理由2：有機・特別栽培は「記録の仕事」です

- **環境保全型農業直接支払交付金** → 環境負荷低減のチェックシート、取組の記録
- **J-クレジット（中干し延長）** → 圃場ごとの水管理日誌、過去2か年の実績
- **有機JAS** → 圃場・資材・作業の全記録
- **みどり認定** → 実施計画の作成

**書類作成、記録管理、計画立案、対外説明。全部、教員が日常的にやっていることです。** ベテラン農家がいちばん苦手にして交付金を取りこぼす部分を、未経験者が初日からやれます。

### 理由3：体験・交流プログラム

北辰農産が収穫祭や田植え体験をやっているように、**教育プログラムの設計は6次産業化の柱**になります。ここは経験年数ではなく教育のプロの領域です。

**結論：栽培技術は3年かけて覚える。その間、制度・記録・販路・教育の側から価値を出す。** これが未経験45歳の唯一勝てる入り方です。

# 5. ドローンは導入すべきか

## 結論：**今は買わないでください。順番が違います。**

理由は4つあります。

### 理由1：戦略と逆を向いています（これが最大の理由）

農業用ドローンの主用途は**農薬散布**です。一方、これまでの提案の柱は**有機・特別栽培（化学肥料・化学合成農薬5割減〜不使用）**です。

**減らそうとしているものを、効率よく撒く機械に投資することになります。** 方向が逆です。

参考までに、知り合いの北辰農産の減農薬米は**除草剤のみの使用で慣行比約73%減**です。この水準まで行くと、防除ドローンの稼働機会はごくわずかになります。

### 理由2：未経験者が最初に買うものではありません

ドローンは**「防除の省力化」であって「儲けを生む機械」ではありません。**

防除の本体は「**いつ、何を、なぜ撒くか**」の判断です。病害虫の発生予察、天候、生育ステージを読む力が先にあって、散布手段はその末端にすぎません。**判断ができない人がドローンを持っても、撒く回数が増えるだけです。**

### 理由3：経済性が合いません

| 項目 | 金額 |
|---|---|
| 機体本体 | **100万〜300万円** |
| 追加費用 | 予備バッテリー、充電器、点検・修理、保険、講習費 |
| **委託した場合** | **1haあたり2万〜3万円** |

自社導入の損益分岐はおおむね**10ha以上**と言われますが、それは**毎年フル稼働させた場合**の話です。減農薬に舵を切れば散布回数自体が減るので、分岐点はさらに遠のきます。

仮に水稲10haなら、**委託で年20万〜30万円**。機体を買えば初期200万円＋維持費です。**当面は委託が圧倒的に合理的です。**

### 理由4：資格と手続きが三重に必要です

農薬散布（目視内での自動飛行＝レベル2飛行）には、以下が**すべて**必要です。

1. **二等無人航空機操縦士**（国家資格）— 試験・身体検査・発行手数料で約1.7万円〜（身体検査を会場受験する場合は別途約2万円、スクール受講料はさらに別）
2. **機体認証** — 国土交通省の認証を受けた機体であること
3. **メーカーライセンス（技能認定証）** — 使用機種ごと
4. **農薬散布認定（UTC・農水協）** — **国家資格はこの代わりになりません。両方必要です**

未経験者が就農初年度にこれを揃えるのは、時間の使い方として明らかに非効率です。

---

## 買うなら、3つの条件が揃ってからです

1. **経営を握って3年以上経ち、防除判断を自分でできるようになった**
2. **受託作業で稼ぐ目算がある** — 委託相場が1ha 2万〜3万円ということは、**受ける側に回れば収入源になります**。北辰農産も農作業受託を事業の柱の一つにしています。ここは伝手が効く領域です
3. **みどり認定を取得済み** — 環境負荷低減事業活動実施計画の認定を受けていれば、**機械の特別償却32%**が使えます。**認定を取る前に買うと、この優遇を丸ごと取り逃します**

## 先に検討すべきは、散布ではなく「センシング」です

ドローンにはもう一つの用途があります。**生育診断・圃場マップ作成・可変施肥**です。

こちらは**有機・特別栽培と方向が一致します。** 肥料を減らしながら収量を保つには、圃場のムラを可視化することが効きます。J-クレジットの中干し延長でも、圃場ごとの排水性の把握が前提になります。

ただし**これも初年度の話ではありません。** まずは委託サービスやJAの共同利用から試すべきです。

---

## 未経験者が最初に投資すべきもの（機械ではありません）

| 優先順位 | 投資先 | 金額感 |
|---|---|---|
| 1 | **研修**（いしかわ耕稼塾） | **無料**（＋就農準備資金が入る） |
| 2 | **記録の仕組み**（営農日誌アプリ、圃場管理） | 年数万円 |
| 3 | **簿記・経営管理** | 研修に含まれる |
| 4 | **認定（認定新規就農者・みどり認定）** | 無料 |
| 5 | **発信**（サイト・EC） | 数十万円 |
| … | | |
| 最後 | **機械・ドローン** | 100万〜300万円 |

**紺多農園に今いちばん足りないのはドローンではなく、ウェブ上の存在です。** サイトもECもふるさと納税も県の生産者カタログへの掲載もありません。機体1台分の予算をここに振れば、効果は桁違いです。

## 6. 未経験45歳のための行動順序（まとめ）

| 時期 | やること | 辞める必要 |
|---|---|---|
| **今〜1年** | 長期休暇・週末に**無報酬で**農作業に入る／**決算書3期分を見る**／北辰農産に話を聞く／白山市農業振興課に相談 | **なし** |
| **1〜2年目** | 配偶者のキャリアと移住の是非を決める／研修の受け入れ先を決める／親族（他の組合員）の合意を取る | **なし** |
| **2〜4年目** | 研修開始（就農準備資金）→ 認定新規就農者 → 組合員加入（経営開始資金） | **あり** |
| **4〜6年目** | 理事・代表理事へ／有機・特栽へ転換／学校給食・食育 | — |
| **6年目以降** | 6次産業化／設備投資（**ここで初めてドローンを検討**） | — |

**49歳までに「就農」の形を整える必要があります。逆算すると、遅くとも47歳までに研修を開始する必要があります。**
