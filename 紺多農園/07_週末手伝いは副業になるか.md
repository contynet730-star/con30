# お兄様が主体で、次男は週末だけ手伝う場合 ― 副業になるか

作成日：2026年9月21日

---

## 結論：無報酬で手伝う限り、副業（兼業）にはなりません。許可も不要です。

公務員が許可なくできる副業には「小規模な農業」と「家業・実家の手伝い」が含まれます。報酬を得ることが目的でなく、かつ無報酬で活動している場合、許可は要りません。

**そして最も重要な点：お兄様が代表理事として経営を担うなら、次男が理事になる必要がありません。** つまり別資料で「決定的な制約」として挙げた**「正規教員は農事組合法人の理事になれない」という問題が、そもそも発生しません。**

---

## 守るべき三つの線

| # | 線引き | 内容 |
|---|---|---|
| 1 | **報酬を受け取らない** | 地方公務員法第38条は「報酬を得て事業又は事務に従事すること」を許可制としています。実家の手伝いであっても、報酬をもらえばルール違反です。農業バイトや有償の援農もまったく同じ扱いです |
| 2 | **組合員・理事にならない** | 営利企業の役員兼業は、名義だけであっても兼業に該当し禁止されます。お兄様が主体なら、次男は組合員にも理事にもならないのが最もシンプルで安全です |
| 3 | **「自営」に当たる規模を超えない** | 人事院規則14―8では「大規模に経営され客観的に営利を主目的とすると判断される場合」が自営に当たるとされます。国や多くの自治体の運用では、**耕地面積30アール未満かつ農産物の年間販売額50万円未満**なら許可なしで可。ただしこれは自分で経営する場合の基準で、**法人が経営主体で次男は労務を提供するだけなら、そもそも次男は「自営」していません** |

---

## 細かいが重要な注意点

- 収穫物（米・野菜）を受け取ること自体は、**自家消費の範囲なら通常問題になりません**。ただしそれを販売して所得が立つと話が変わります
- 確定申告で農業所得が立つと、住民税の通知経由で勤務先に把握される可能性があります
- 「無報酬である」ことを後から説明できるよう、**家族経営協定などで役割分担を書面化**しておくと安全です
- 交通費や資材費の**実費精算は報酬ではありません**が、実費を明らかに超える支給は報酬とみなされ得ます
- **判断に迷う要素が一つでもあるなら、勤務先の服務担当に事前相談してください。** 事後に問題化するより、事前に確認して記録を残すほうが圧倒的に安全です

## この前提での最適解：案D

| | 案D（お兄様が主体・次男は週末手伝い） |
|---|---|
| 次男（45歳） | 石川県の正規教員（730〜780万円）＋ 週末に無報酬で手伝う |
| 配偶者（47歳） | 石川県の正規教員（650〜700万円） |
| **世帯合計** | **1,380〜1,480万円**（現状比 ▲220〜320万円） |
| 金融資産＋家の売却益 | 5,000万〜8,400万円（年収差を15〜38年吸収できる） |
| **理事就任の問題** | **発生しない（理事にならないため）** |
| 農業の経営リスク | ほぼ負わない |
| 就農支援金 | 対象外（就農しないため）。お兄様が対象になるかは年齢次第で要確認 |
| 可逆性 | 最も高い |

なお石川県の教員採用試験は、令和6年度採用試験から受験年齢制限が50歳未満から**60歳未満**に緩和されており、45歳・47歳とも受験資格に問題はありません。前歴加算10割で号給も引き継げ、退職手当も通算を選べます。

### 案Dは、現時点で最もリスクが低く、最も合理的な選択肢です

- 世帯収入の減少は▲220〜320万円にとどまり、資産で15〜38年吸収できます。しかも移住で生活費自体が下がるため、実質の差はさらに小さくなります
- 農業の経営リスク（借入、米価変動、天候）をお兄様が負い、次男は労働力と、制度・記録・販路・発信という得意分野で支える。無理のない分業です
- **ただし論点が一つ移ります。承継の主体はお兄様なので、承継手続き・年収・就農ルート・設備投資の分析は、次男ではなくお兄様に向けた内容として読み替えてください**

---

## 案Dで新たに確認すべきこと

1. **お兄様の年齢。** 49歳以下なら経営開始資金（年150万円×3年）の対象になり得ます
2. **お兄様がすでに組合員・理事かどうか。代表理事は誰か**
3. **お兄様に万一のことがあった場合の承継設計。** 次男が急に理事になる必要が生じたとき、正規教員のままでは就任できません。この備えは今のうちに話し合っておくべきです
4. **次男の関与を「労働力」に留めるのか、「資金・制度・販路の支援」まで広げるのか。** 後者のほうが、週末の労働力より価値が大きい可能性があります
