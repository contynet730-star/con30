# 教育行政研修「教育課程と練馬区の小中一貫教育」発表一式

令和8年度 教育行政研修（対象：小・中学校籍の先生方 5名／持ち時間30分＝説明約25分＋質疑約5分）用に作成した、発表スライドと発表原稿の一式です。

## 収録物

| ファイル | 内容 |
|---|---|
| `発表スライド_教育課程と練馬区の小中一貫教育.pptx` | 発表用スライド（全23枚、16:9）。各スライドに話す内容の要点をノートとして格納済み。 |
| `発表原稿_教育課程と練馬区の小中一貫教育.docx` | 発表スクリプト。進行のめやす（通過時刻つき）、スライドごとの読み原稿、想定問答（Q&A）を収録。 |
| `スライドプレビュー_全23枚.pdf` | スライドの見た目確認・印刷用プレビュー。 |
| `src/` | 再生成用のスクリプト（`deck.js`＝スライド、`make_script.py`＝原稿）と、流用した画像素材。 |

## 構成（25分＋質疑5分）

- **導入（S1–2, 約2分30秒）** ねらい・流れ／2つのテーマは「9年間の学びの連続性」で一本につながる、と最初に提示。
- **第1部：教育課程とその管理（S3–10, 約10分）** 教育課程とは何か → 地教行法21条での位置づけ → 管理＝PDCA → 指導主事による管理の4視点 → 学校訪問での指導・助言4点 → 「連続性」への橋渡し。
- **第2部：練馬区の小中一貫教育（S11–21, 約10分30秒）** 求められる背景・小中の差異・不登校データ（中1ギャップ）→ 定義と3つの目的 → 区の規模・推進の仕組み（33中学校区グループ／知的障害学級小中グループ／クリエーター）→ 施設一体型2校 → 令和8年度の重点取組・多様な取組。
- **まとめ（S22–23, 約1分30秒）** 3点のまとめ＋配布資料案内 → 質疑応答へ。

## 「新規PPTXを作るか、もとの資料を活用するか」の検討結果

**結論：本研修用には “新規スライド” を作成し、もとの2資料は “配布資料” として併用する構成を推奨します。**

理由は、今回の条件（①教育課程と小中一貫の2テーマを、②25分で、③5名の少人数に、④行政研修として）に、既存資料がそのままでは合致しないためです。

- **もとの小中一貫スライド（都丸統括指導主事・4/27研修用）** は完成度が高い一方、(a) 小中一貫の1テーマのみで「教育課程・教務」を含まない、(b) 60〜90分規模の研究研修向けで24枚あり25分では長い、(c) 話者・場面が異なる、という不一致があります。
- **もとの2資料（教育行政研修資料＝教育課程の管理／令和8年度小中一貫教育の取組について）** は情報が正確で詳細ですが、条文・実務の手引・年間予定などテキスト中心で、投影して語る発表スライドには不向きです。

そこで本一式では、
1. 2テーマを **「9年間の学びの連続性」** という一本の軸で束ね直し、25分・少人数向けに再設計した新規スライドを用意。
2. 小中一貫の **実データ（令和6年度 不登校児童生徒数）と施設一体型2校の写真** は、もとのスライドの正確な素材を流用（区の公式資料）。
3. **条文（地教行法21条）・教育課程管理のポイント（東京都「指導主事実務の手引」）・年間予定などの詳細** は、もとの2資料を配布資料として案内（スライドは軽く保つ）。

→ 「スライドは論点、詳細は手元資料」と役割分担することで、限られた25分でも2テーマを無理なく扱えます。

## 出典・流用素材

- 「令和8年度 小中一貫教育の取組について」（練馬区教育委員会）… 定義・必要性・3つの目的・重点取組・グループ構成・年間予定
- 「令和8年度 教育行政研修資料」（教育課程の管理）… 地教行法21条、教育課程の管理／学校訪問のポイント、東京都「指導主事実務の手引（令和5年3月）」
- 既存スライド「練馬区の小中一貫教育」… 背景・小中の差異・令和6年度不登校児童生徒数・区の規模・施設一体型校（大泉桜学園／みらい青空学園）の写真

## 再生成の手順

```bash
cd src
node deck.js            # → deck.pptx を出力（要 pptxgenjs）
python3 make_script.py  # → script.docx を出力（要 python-docx）
```

数値・文言の修正は `src/deck.js`（スライド）と `src/make_script.py`（原稿）を編集して再実行してください。
