# 60歳リタイア逆算プラン

**前提**：45歳 ／ 金融資産 1,500万円 ／ 毎月の積立 5万円 ／ 60歳で退職

| ファイル | 内容 |
| --- | --- |
| `60歳リタイア逆算プラン.html` | 設計書本体（ブラウザで開く） |
| `simulation.py` | 全数値の試算スクリプト（`python3 simulation.py`） |

---

## 結論

1. **買うのは全世界株式インデックス1本** — eMAXIS Slim 全世界株式（オール・カントリー）、信託報酬 年0.05775%以内。つみたて投資枠でも成長投資枠でも同じものを買う。
2. **月5万円は全額NISAに入れず、iDeCo 2万＋NISA 3万に割る** — 既存1,200万円を成長投資枠に入れるとNISA生涯枠は54歳で埋まり、以降の積立は課税口座行きになる。最初から割れば所得控除を15年分受け取れて **60歳時点で約80〜100万円得する**。
3. **既存1,200万円は5年かけて成長投資枠へ、300万円は現金で残す** — 年間投資枠360万円の制約上、1,200万円は一括では入らない。年240万円×5年（45〜49歳）が最速。

## NISA枠の使い方

成長投資枠 240万円×5年 ＋ つみたて投資枠 36万円×15年 ＝ **1,740万円**（生涯枠1,800万円に収まり、成長投資枠は上限1,200万円ちょうど）。

| 年齢 | 成長投資枠 | つみたて投資枠 | NISA累計 | iDeCo |
| --- | ---: | ---: | ---: | ---: |
| 45〜49歳 | 240万 ×5年 | 36万 ×5年 | 1,380万 | 24万/年 |
| 50〜54歳 | ─ | 36万 ×5年 | 1,560万 | 24万/年 |
| 55〜59歳 | ─ | 36万 ×5年 | 1,740万 | 24万/年 |

最初の5年は年300万円の拠出になるが、内訳は「既存資金から240万円＋給与から60万円」で新たな負担増ではない。

| 22万円 | 100歳超も安泰 | 100歳超も安泰 | 100歳超も安泰 |
| 25万円 | 88歳で枯渇 | 100歳超も安泰 | 100歳超も安泰 |
| 28万円 | 79歳で枯渇 | 100歳超も安泰 | 100歳超も安泰 |

**3%の列で成立するかどうかが実質的な合否。** 月22万円までなら現状のままで成立する。

## 足りない場合のレバー（3%成長・生活費 月25万円）

| 手 | 結果 |
| --- | --- |
| そのまま | 88歳で枯渇 |
| ① 積立を月5万→月8万に増額 | 100歳超も安泰 |
| ② 60〜65歳だけ月8万円ぶん働く | 98歳まで持続 |
| ③ 生活費を月25万→22万に圧縮 | 100歳超も安泰 |
| ④ 年金を70歳まで繰り下げ（+42%） | 93歳まで持続 |
| ②＋③ の合わせ技 | 100歳超も安泰 |

①か③なら単独で解決する。②と④は単独では100歳に届かないため、組み合わせて使う。

## 注意点

- 金額はすべて名目値。インフレを見るならリターンから年1〜2%を引く。
- 公的年金は「65歳から年180万円」の仮定。実額はねんきんネットで要確認。
- 58歳から、リタイア後5年分の生活費を現金・個人向け国債に移す（収益率配列リスク対策）。
- 2026年1月から、退職金とiDeCo一時金の退職所得控除の重複調整期間が5年→10年に延長。退職金がある場合は受け取り方を要検討。
- iDeCoの拠出限度額は2026年12月に会社員 月6.2万円へ引き上げ。
- 一般的な情報提供であり、個別の投資助言ではない。
