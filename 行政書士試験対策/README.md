# 行政書士試験 毎日30分トレーニングプログラム

平日の昼休み(12:00〜13:00のうち30分)で完結する、行政書士試験対策プログラムです。

## 使い方

1. `index.html` をパソコンまたはスマートフォンにダウンロードして、ブラウザで開くだけで使えます(インターネット接続・インストール不要)。
2. 毎日「▶ 今日の30分を始める」を押すと、その日のメニューが自動で出ます。
3. 学習記録(連続日数・正答率・記述の点数・間違えた問題)は端末のブラウザに自動保存されます。
   - 注意: 同じ端末・同じブラウザで続けてください。ブラウザの履歴削除をすると記録も消えます。

## 毎日30分の構成(12:00〜12:30 を想定)

| 時間 | 内容 | ねらい |
|---|---|---|
| 3分 | 法律用語・言い回しドリル(3語) | 苦手な「法律特有の言い回し」を毎日浴びる |
| 8分 | ミニ講義(1テーマ) | 全33テーマを約7週間で1周 → 試験まで約3周 |
| 12分 | ○×一問一答(6〜8問) | 講義と同じ科目+前回間違えた問題を自動で再出題 |
| 7分 | **記述式トレーニング(1問)** | **昨年0点だった記述(60点分)を毎日1問、必ず手で書く** |

## あなたの状況に合わせた設計

昨年度の結果(全体5割・記述0点)から、合格までの最短ルートは次のとおりです。

- **合格基準は300点満点中180点(6割)+ 法令等122点以上・基礎知識24点以上の足切り。**
  昨年5割なら、あと30点前後の上積みで合格圏です。
- **記述式は3問×20点=60点。** ここが0点だったということは、最大の伸びしろがここにあります。
  記述で30点(半分)取れるようになるだけで、ほぼ合格ラインに届く計算です。
  → だから本プログラムは**記述を毎日1問**、最後のステップに固定しています。
- **記述の出題は例年「行政法1問+民法2問」。** 収録30問もこの2科目に絞っています。
  模範解答のキーワードにチェックを入れる自己採点方式で、本試験の部分点の感覚が身につきます。
- **法律の言い回しが苦手** → 用語辞典45語(「及び/並びに」「みなす/推定する」「善意/悪意」など)を
  毎日3語ずつローテーション。さらに毎日の講義に「言い回しチェック」コーナーを付けています。
  条文の読み方そのものを訓練するので、択一のひっかけにも強くなります。

## 試験日までのスケジュール(2026年6月〜11月)

令和8年度試験は **2026年11月8日(日)13:00〜16:00** が想定日です(例年11月第2日曜)。

| 期間 | 位置づけ | 30分の使い方 |
|---|---|---|
| 6月中旬〜7月 | 1周目: 基礎の立て直し | プログラムどおり。○×の正答率より「解説を読んで納得する」ことを優先 |
| 8月〜9月中旬 | 2周目: 精度を上げる | 同じテーマが2周目で出ます。記述は模範解答を見ずに書き切る練習へ |
| 9月下旬〜10月 | 3周目: 弱点つぶし | 「弱点復習」タブを毎日のメニューの前後に追加。進捗タブで正答率70%未満の科目を重点的に |
| 11月第1週 | 最終確認 | 記述30問の模範解答キーワードと用語辞典45語の総ざらい |

### 平日30分以外に、可能ならやってほしいこと

- **土日のどちらかで市販の過去問・模試を時間を計って解く**(本試験は3時間の長丁場。30分学習だけでは本番の体力がつきません)。10月に最低2回は模試形式を。
- 一般知識等(基礎知識)科目は本プログラムの対象外です。足切り(24点)回避のため、文章理解の過去問と時事・情報通信(個人情報保護法等)を土日に補ってください。

### ⚠️ 受験申込を忘れずに

受験申込は**例年7月下旬〜8月下旬**です。「一般財団法人 行政書士試験研究センター」の
公式サイト(https://gyosei-shiken.or.jp/)で日程を確認し、必ず期間内に申し込んでください。

## 収録コンテンツ

- ミニ講義: 33テーマ(基礎法学2・憲法5・民法13・行政法11・商法2)
- ○×一問一答: 110問(解説付き・間違えた問題は自動で復習リスト入り)
- 記述式トレーニング: 30問(行政法15・民法15、模範解答+キーワード自己採点)
- 法律用語・言い回し辞典: 45語(いつでも検索・閲覧可能)

※ 収録内容は2026年6月時点の法令・判例に基づく学習用の要約です。最終確認は市販テキスト・六法で行ってください。
